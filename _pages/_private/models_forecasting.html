– 3b_ModelFit_BiasVariance.ipynb

PURPOSE OF THIS NOTEBOOK:

  • to choice a model from a given architecture using the bias-variance tradeoff criteria

  • to assess the model with a train-test-validation data split.

INPUTS:

  • a model

  • data file with processed data

  • train/test split rate

  • loss function

OUTPUTS:

  • the final model is saved as a joblib file

  • experiments are registered with mlflow

NOTES:

  • this notebook must be run using either the i3ml conda environment

  • Input files are generated using DataPrep_1hot, DataPrep_CatEncoding or DataPrep_embedding

  • this notebook is specific for the XGBoost model, for different models the complexity parameters could change
